# Maintainers

This file is the source of truth for who maintains ccctl. It is mirrored to GitHub repository permissions: maintainers have write access, everyone else does not.

Maintainers can merge a pull request to `main` once every required CI check has passed. No approving review is required, and nobody outside this list can merge.
