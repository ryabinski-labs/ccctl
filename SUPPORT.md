# Support

ccctl is maintained by volunteers, with no support commitment or response-time guarantee.

| You want to | Do this |
|---|---|
| Ask a question or share how you use it | Open a [GitHub Discussion](../../discussions), or an issue if Discussions are off. |
| Report a bug | Open an issue with the bug report form. Include your OS, `ccctl` release tag, and the relevant lines from `~/.ccctl/logs/`. Remove any secrets first. |
| Request a feature | Open an issue with the feature request form. Describe the problem before the solution. |
| Report a security problem | Follow [SECURITY.md](SECURITY.md). Do not open a public issue. |

## Out of scope

- Problems with Tailscale, Claude Code, or macOS itself. Check their documentation first.
- Hosts other than macOS and Linux on arm64 and amd64.
- Exposing ccctl to the public internet or to people outside your tailnet. It is not designed for that.
